# tokenusage — logo explorations (v0)

40 hand-authored SVG concepts spanning four directions:
1. **Data-viz marks** (bars / charts / counters / gauges)
2. **Sol-inspired** geometric bands
3. **Monogram / wordmark** typography
4. **Code-flavored** brackets / cursors / parens

All marks use the brand indigo `#5B5BF2` (matches the in-app accent). Sol-style variants pair it with cyan `#22D3EE` for the gradient. Wordmarks use Geist Mono.
